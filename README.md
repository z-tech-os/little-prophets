## About This Website

This is a pure HTML, CSS & JavaScript website designed for children and parents.  
It contains **full, kid-friendly stories** of the major Prophets written in simple, playful language so that children understand quickly and parents feel confident reading them.

### Features
- Full stories (not just short summaries)
- Clear moral lessons at the end of each story
- Beautiful cherry-red & white theme + Dark mode
- Responsive design (works on phones, tablets, computers)
- Mobile sidebar navigation
- Loading animation
- Offline support (Service Worker)
- Perfect SEO meta tags with creator name “Mustapha Gbanie”
- No backend, no forms – ready for GitHub Pages

### Prophets Included
1. Prophet Adam (AS)
2. Prophet Nuh (AS)
3. Prophet Ibrahim (AS)
4. Prophet Yusuf (AS)
5. Prophet Musa (AS)
6. Prophet Isa (AS)
7. Prophet Muhammad ﷺ

## How to Use / Host

1. Upload the entire folder to a GitHub repository.
2. Go to **Settings → Pages**.
3. Select the main branch and `/ (root)` folder.
4. Your site will be live at:  
   `https://yourusername.github.io/repository-name/`

Suggested repository name: `prophets-for-kids` or `little-prophets`
